## 📝 How to Use This Data

### **Load into Database**
```bash
# After running schema.sql
psql -U your_user -d house_party_db -f seed_data_comprehensive.sql
```

### **Generate Embeddings**
```python
# Run this after loading data
from backend.services.embeddings import embed_text
from database import session

facts = session.query(GroundTruthFact).all()
for fact in facts:
    text = f"{fact.key}: {fact.value}"
    embedding = embed_text(text)
    fact.embedding = embedding
session.commit()
```

### **Test Queries**
```python
from backend.services.ground_truth_query import query_ground_truth

# Should work via keyword match
query_ground_truth("What's the address?", event_id="event001-...")
# → "123 Trousdale Parkway, Los Angeles, CA 90007 (Starbucks USC)"

# Should work via semantic search
query_ground_truth("Where can I leave my car?", event_id="event001-...")
# → "Street parking on Trousdale or Parking Structure X on Figueroa"

# Should escalate
query_ground_truth("Can I bring my dog?", event_id="event001-...")
```
